# Set Notes 1.0.0 — evidence-based review preparation

Draft only. No App Store Connect upload, submission or review message is authorized by the scheduled workflow. These answers must be reconciled with the eventual uploaded binary and any current review request. Never claim external beta testing or market exclusivity without evidence.

1. **Function and problem.** Set Notes is an offline resistance-training notebook. A user starts a workout, picks an exercise or enters its name, records weight and repetitions independently, optionally marks warmup or bodyweight work, writes a set note, and marks completed sets. Stable set IDs and serialized device saves preserve edits and completion state. A rest deadline continues across app lifecycle recovery. The user can reuse an unchecked routine, copy prior values explicitly, finish and edit a dated history entry, inspect progress, change kg/lb without reinterpreting stored weight, and export or restore a validated JSON notebook. Its primary problem is retaining a clear, controllable set record during training without login, subscription or social setup.

2. **Audience.** Adults who perform resistance training and want a manual exercise notebook, including users recording weighted and bodyweight sets, warmups and short notes. It is intended for people who prefer a focused on-device log over coaching, public feeds or health-account integration. No medical diagnosis, Watch support or health-data synchronization is offered.

3. **Observed needs.** The daily research reviewed dated, versioned low-star Strong and JEFIT reviews in official App Store RSS feeds. Sample complaints included disappeared workout history, missing notes, changed or complicated entry flows, repeated-weight friction, feature/premium/AI clutter, and bodyweight values. Set Notes addresses this selected workflow with local persistence, stable IDs, explicit previous-value copying, independent warmup/bodyweight flags, notes, and user-controlled backups. These examples are bounded review samples; they do not establish that competitors currently lack all these features or that no comparable product exists.

4. **Testing.** Automated unit/widget checks cover restart recovery and stable IDs, volume exclusions, kg/lb conversion, fresh routine set IDs, saved history editing, invalid backup rejection, incomplete inputs, and preservation of corrupt storage. Native Android/iPhone/iPad integration evidence is recorded separately with actual run outcomes. No external beta-test participants or feedback have been verified. Do not describe these automated checks as TestFlight beta feedback. If Apple requests beta feedback, genuine testing and resulting changes remain required.

5. **Portfolio.** Related account apps include Tempo Rounds (interval timing), Today Weather Outfit (weather-based clothing suggestions), Round Ledger (group score keeping), Unit Tally (unit-price comparisons), Walk Journal (walk entries), Fridge First (food inventory/expiry workflow), and Shift Blocks (shift planning). Set Notes records individual exercise sets and workout history. It does not claim these other app functions. Confirm the account's complete current app list before any answer is sent.

6. **Consolidation.** No existing portfolio app currently implements this workout notebook's exercise/set model, completion tracking, routines and workout backup schema. An expanded existing app could technically add that domain, but that has not been implemented. The standalone scope provides a direct workout-entry experience without making unrelated workflows prerequisites. This explains the current design, not a guarantee that Apple will accept the distinction.
